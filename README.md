## 🚀 Overview

Developed an end-to-end retail sales forecasting pipeline using **LightGBM** and **XGBoost** within the **DARTS** framework to predict daily sales across multiple stores and product families. The workflow combines feature engineering with external factors such as holidays, promotions, and oil prices to improve forecasting accuracy.
